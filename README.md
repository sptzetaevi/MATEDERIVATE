# Percorso sulle derivate

Sito statico pronto per GitHub Pages.

File principali:
- `index.html`: pagina iniziale
- `passo1_derivate_base.html`: derivate di base
- `passo2_esponenziale_logaritmo.html`: e^x e ln(x)
